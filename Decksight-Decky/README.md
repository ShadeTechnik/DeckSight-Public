# DeckSight Decky-Loader plugin

Currently just adds a UI entry to toggle brightness overlay adjusted via the regular slider in Gamescope. Main python code from https://github.com/Xnopyt/decksight-brightness-fix

## Usage
* Download the Realease package or let the DeckSight install script do it for you https://www.shadetechnik.com/s/DeckSightdesktop.download
* Go to Decky settings and enable "Developer Mode"
* In the Developer tab, select "Install Plugin from ZIP File"
* Select Decksight-Decky...zip (The installer will place this right in the home folder)
* There will be a DeckSight pllugin shown in the Decky plugin select menu. You can toggle this on or off. When on, the normal brightness slider will control the brightness overlay.

## Notes
* The overlay effects mostly everything, but Mangohud (The FPS thing) os generally not effected so it will sometimes appear at full brightness while everything else has been dimmed. This is a Gamescope limitation.
